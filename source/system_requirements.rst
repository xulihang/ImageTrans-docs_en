System Requirements
==================================================

Operating Systems
--------------------

* Windows 7 and above
* macOS 10.11 and above
* Linux

Import Formats
--------------------

* Images: webp, jpeg, png, gif, bmp, tiff
* Documents: pdf, mobi, cbz, epub

Export Formats
--------------------

* Images: ora, jpeg, webp, png, psd
* Documents: pdf
